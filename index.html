Exemple : une quête de A à ZExample: one quest from A to Z

Q_001 · First Contact

La toute première quête : descendre du train, retrouver Sébastien, rejoindre la casse dans le temps imparti, puis lui reparler. La même quête, vue dans chaque outil que j'utilise.

The very first quest: get off the train, find Sébastien, reach the junkyard in time, then talk to him again. The same quest, seen in each tool I use.

  1. 1
    Je l'écris dans mon classeur de quêtesI write it in my quest workbook

    Un onglet par quête : identité, enchaînement, textes affichés au joueur, étapes et dialogues. Chaque texte calcule sa clé de localisation et vérifie qu'elle est bien dans le LocKit, avec le même texte.

    One tab per quest: identity, chaining, player-facing texts, steps and dialogues. Each text builds its localization key and checks it is in the LocKit, with the same text.

  2. 2
    Les textes partent dans la localisationThe texts go to localization

    Titre, description, objectifs et répliques deviennent des lignes du fichier de localisation, avec la même clé que dans le classeur.

    Title, description, objectives and lines become rows of the localization file, with the same key as in the workbook.

  3. 3
    Je l'intègre dans UnityI integrate it in Unity

    Dans le catalogue de quêtes : une étape par objectif, le PNJ à faire apparaître, le dialogue qui lance la quête, et les textes qui pointent vers les clés du LocKit.

    In the quest catalog: one step per objective, the NPC to spawn, the dialogue that starts the quest, and texts pointing to the LocKit keys.
